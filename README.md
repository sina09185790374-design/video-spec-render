# video-spec-render 🎬

**Declarative JSON spec in → rendered MP4 out.** Built for agents: describe the cut (scenes, backgrounds, text, music), a compiler renders the pixels via ffmpeg — no footage required.

Inspired by the pattern behind [heygen-com/hyperframes](https://github.com/heygen-com/hyperframes) ("Write HTML. Render video. Built for agents"): agents should *describe* video, not hand-edit frames. Original implementation, stdlib-only Python.

## Quick start

```bash
python3 main.py demo                    # renders examples/reel3.json -> demo_reel.mp4 (no network)
python3 main.py validate examples/reel3.json
python3 main.py render spec.json out.mp4 --music bed.mp3 --check-audio
python3 -m unittest discover -s tests -v
```

Needs `ffmpeg` (and `ffprobe` for the audio gate) on PATH.

## Spec format

```json
{
  "canvas": {"width": 1080, "height": 1920, "fps": 30},
  "scenes": [
    {
      "duration": 3.0,
      "background": {"kind": "gradient", "from": "#0D1220", "to": "#1B2A4A"},
      "overlays": [
        {"text": "SALE", "size": 96, "y": 700, "color": "#FFFFFF", "box": true}
      ]
    },
    {
      "duration": 2.0,
      "background": {"kind": "video", "file": "clip.mp4"}
    }
  ],
  "music": {"file": "bed.mp3", "volume": 0.5, "fade_out": 1.0},
  "out": {"crf": 18, "preset": "medium"}
}
```

- **background kinds**: `solid` / `gradient` (generated by ffmpeg, zero footage) / `video` (looped, cropped to fill).
- **overlays**: `text` (Latin scripts) or `image` (PNG path). Default text position is the **bottom-safe zone** (`y = height − 360`) so captions never cover the subject.
- **music**: muxed with fade-out; `--check-audio` enforces the **−50 dB gate** — a silent track fails the render instead of shipping quiet.

### Persian text

ffmpeg `drawtext` cannot shape Persian/Arabic. Pre-render Persian captions to PNG with a proper shaping pipeline (e.g. Pillow + libraqm, logical order, `direction="rtl"`) and burn them in with an `image` overlay.

## Structure

```
specrender/spec.py    spec validation (fail-fast, clear errors)
specrender/render.py  ffmpeg command builder + runner (single invocation)
specrender/audio.py   volumedetect gate: mean_volume must beat -50 dB
main.py               CLI: validate | render | demo
examples/reel3.json   3-scene sample spec (bottom-safe text zones)
tests/                12 validation tests + 4 real-render integration tests
```

## فارسی

**video-spec-render** — از روی الگوی پروژه hyperframes ساخته شده («مشخصات ویدیو بده، ویدیو تحویل بگیر — برای ایجنت‌ها»): به‌جای ویرایش دستی فریم‌ها، ایجنت فقط یک فایل JSON ساده توصیف می‌کند (صحنه‌ها، پس‌زمینه، متن، موزیک) و ابزار با ffmpeg خروجی MP4 دقیق می‌سازد — بدون نیاز به فوتج آماده.

- پس‌زمینه‌های `solid` و `gradient` مستقیم با ffmpeg تولید می‌شوند؛ ویدیوی واقعی هم می‌تواند لوپ شود.
- متن‌ها به‌صورت پیش‌فرض در **ناحیه امن پایین فریم** قرار می‌گیرند (y = ارتفاع − ۳۶۰) تا روی سوژه نیفتند.
- گیت صوتی **−۵۰ دسی‌بل**: ترکِ عملاً بی‌صدا رد می‌شود و منتشر نمی‌شود (همان قانونی که خودمان موقع انتشار ریل رعایت می‌کنیم).
- متن فارسی: drawtext فارسی را درست رندر نمی‌کند؛ کپشن فارسی را اول به PNG تبدیل کنید و با overlay نوع `image` بسوزانید.

اجرا: `python3 main.py demo` — بدون اینترنت، فقط ffmpeg لازم است. فقط کتابخانه استاندارد پایتون؛ بدون توکن و کلید.
